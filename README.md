# Enbull Oil Change Tracker

A frontend-only internship project for a motorcycle lubricant company. It records oil changes, calculates the next service date/mileage, and highlights records that are due soon or overdue.

## Run locally

Open `index.html` in a browser, or deploy the three files to Vercel, Netlify, or GitHub Pages. No installation or backend is needed.

## Features

- Login/logout stored locally in the browser
- Dashboard and sample data
- Add, edit, view, delete, search, filter, and export service records
- Automatic service intervals for Enbull oil products
- Product catalogue, mechanic profile, and project-about pages
- Browser localStorage persistence
